# Lumen — Legal & Privacy

This repository hosts the publicly-reachable privacy policy and other legal pages for **Lumen**, a privacy-first AI assistant for iPhone and iPad.

The live page is published via GitHub Pages at:

**https://eulicesl.github.io/lumen-legal/**

That URL is the one Lumen links to from inside the App Store listing and the app's Settings screen.

## What's here

- `index.html` — the privacy policy, served as the site's root page.

## Updating the privacy policy

1. Edit `index.html` directly (it's intentionally a single standalone file).
2. Update the `Last updated` date near the top.
3. Commit and push to `main`.
4. GitHub Pages rebuilds automatically, usually within a minute.
